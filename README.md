# Data Center Desk

A public working reference on data centers, power, and the Illinois legislative process, published with GitHub Pages.

- `index.html` is the home page. Open `map.html` for the interactive map.
- `assets/` holds the shared styles, scripts, and data.
- `archive/` holds the older hub pages and Word files, with an index at `archive/index.html`.

Numbers on every page carry their source and date. Company positions shown are proposals and not approved policy.
