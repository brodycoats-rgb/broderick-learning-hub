# Broderick Learning Hub

HTML repository for reports, notes, learning, and personal initiatives, published with GitHub Pages.

- `index.html` is the Learning Hub home page.
- Files that start with `dcd-` are the Data Center Desk, a public reference site on data centers, power, and Illinois, with an interactive map. Start at `dcd-index.html`.
- `archive.html` lists the earlier data center pages, their Word files, and the healthcare policy page.

Numbers on the Data Center Desk carry their source and date. Company positions shown there are proposals and not approved policy.
