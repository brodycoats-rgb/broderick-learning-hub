# Broderick Learning Hub

HTML repository for reports, notes, learning, and personal initiatives, published with GitHub Pages.

- `index.html` is the Data Center Desk home page. Open `map.html` for the interactive map.
- `hub.html` is the Learning Hub home page for the other guides and dashboards.
- `assets/` holds the shared styles, scripts, and data for the Data Center Desk.
- `archive/` holds the older data center and healthcare pages, with an index at `archive/index.html`.

Numbers on every page carry their source and date. Company positions shown are proposals and not approved policy.
